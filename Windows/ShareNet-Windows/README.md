# ShareNet для Windows

Автономное портативное приложение **ShareNet.exe** для Windows 10/11 (Go + WebView2) с режимом «2 в 1»: работает и на компьютере с интернетом (раздача по USB), и на принимающем ноутбуке/ПК (приём по Wi-Fi или USB через телефон).

## Возможности

1. **Вкладка «Раздача»** *(ПК с интернетом → USB → Android)*:
   - находит Android по USB (`adb`), устанавливает/обновляет `gnirehtet.apk` и `ShareNet.apk`, отключает мешающий Private DNS на время сеанса и возвращает его при остановке;
   - поднимает реверс-туннель `gnirehtet` + локальный SOCKS5-сервер `127.0.0.1:10808` и запускает **ShareNet** (`:8080`) на телефоне;
   - встроенные утилиты: отправка APK/файлов на телефон, открытие настроек точки доступа, запуск терминала ADB.
2. **Вкладка «Приём»** *(ПК/ноутбук ← Wi-Fi точка доступа или USB телефона)*:
   - автоматически определяет IP-шлюз телефона или позволяет задать адрес вручную;
   - **Полный VPN (TUN)** (`sing-box.exe` + DoH `1.1.1.1`) — заворачивает весь системный трафик и DNS;
   - **Системный прокси** — включает SOCKS5 в параметрах Windows без прав администратора с автоматическим откатом;
   - проверка сети (`generate_204`) и быстрая настройка прокси для Telegram (`:8080`).
3. **Вкладка «Сброс»**:
   - статус модулей, журнал событий, кнопка **«Отключить всё и откатить»** для возврата сети, DNS и системного прокси;
   - ссылка на профиль разработчика: [github.com/TPpixel](https://github.com/TPpixel).

## Запуск и сборка

- **Root-раздача (автоматически в `ShareNet.exe`):** при подключении рутованного Android (Magisk / KernelSU / APatch) `ShareNet.exe` автоматически определяет Root (`· Root`) и использует туннель `sing-box` (`adb reverse` -> `tun0` с перехватом DNS на `:1053` и `iptables`), благодаря чему ноутбуки и другие телефоны выходят в интернет напрямую через Wi-Fi без установки приложений и настройки прокси.
- **Готовый запуск:** запустите `ShareNet.exe` (все утилиты — `adb`, `gnirehtet`, `sing-box`, `ShareNet.apk` — встроены внутрь exe и распаковываются в `%LOCALAPPDATA%\ShareNet\runtime` при старте). Для запуска с сетевой папки используйте `ShareNet_Start.bat`.
- **Сборка из исходников (Go 1.21+):**
  ```powershell
  .\build.ps1
  ```
  Скрипт собирает ресурсы (`cmd/mkres`), упаковывает `internal/embedded/tools.zip` и компилирует единый `dist\ShareNet.exe`.
